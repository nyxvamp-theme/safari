# nyxvamp (safari)

a minimalist theme collection, inspired by a blend of gothic and emo aesthetics with transfem symbolism. it combines deep purples and soft yellows with neutral tones to create strong contrasts and a comfortable web browsing environment that reflects individuality.

## variations

1. **veil**: versatile theme for both day and night, featuring bright accents on a dark background.

2. **obsidian**: dark theme for focused nighttime browsing sessions.

3. **radiance**: light theme optimized for daylight use, ensuring excellent readability.

## usage

1. download files
   - `nyxvamp-veil.css`
   - `nyxvamp-obsidian.css`  
   - `nyxvamp-radiance.css`
2. install a safari extension
   - [stylish for safari](https://apps.apple.com/us/app/stylish-custom-themes-for-websites/id1448749896)
   - [cascadea](https://apps.apple.com/us/app/cascadea/id1432182561) (premium but more features)
3. apply the theme
   - open your extension
   - create a new style
   - paste the contents of your chosen theme file
   - set it to apply to "all urls" or specific domains
